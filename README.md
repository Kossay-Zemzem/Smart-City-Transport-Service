# Transport Service (Service Transport)

> [!NOTE]
> This service is part of a microservice orcherstration project. For full details, please visit the **[Smart City Microservices Project](https://github.com/Kossay-Zemzem/Smart-City-Microservices)** main repository.

## Service description

The Transport Service is a core component of the Smart City platform that manages public transport information. It exposes the network’s transport lines, the trips associated with each line, and the terminals served, allowing client applications to browse routes and plan journeys.

## Tech Stack

* **Framework:** Spring Boot
* **API Style:** REST
* **Database:** H2
